# 耗时一个多月的建站历险记

今天，看着屏幕上完美的蓝白主题、会说话的阿罗娜看板娘，以及我自己的专属域名 `jackhutton.cc.cd`，我终于长长地舒了一口气。

其实，这个网站是我从暑假就开始折腾的，满打满算，**整整搞了一个多月**。今天借着写第一篇文章的机会，记录一下这一个多月的“血泪史”。

## 🛠️ 折腾的第一步：寻找与部署
最开始，我在 GitHub 上看到了这个基于 VitePress 的 **BlueArchive（蔚蓝档案）** 主题，一眼就相中了它的排版和二次元风格。
但是，把 GitHub 上的模板变成自己的网站，简直是一部劝退史。最开始想用 GitHub Pages，结果因为路径配置（`base`）的问题，网页直接白屏，样式全丢。

后来，我转向了 **Netlify**。面对全英文的后台，我不知道填错了多少次 Build Command 和 Output Directory，才终于让它成功跑起来。

## 🌐 痛点：域名与网络
网站跑起来了，但 `netlify.app` 的免费域名又长又难记。于是，我去弄了一个免费的 `cc.cd` 域名。为了把域名绑上去，我又去啃了 DNS 解析、A 记录、CNAME 记录这些以前完全看不懂的东西。

更折磨人的是国内网络环境。用 Netlify 的免费额度很快就用光了，网站无法更新；想换 Vercel，结果默认分配的 `vercel.app` 域名又被国内网络屏蔽（墙了）。

最终，我还是通过自己的独立域名解析到 Vercel，才终于解决了国内访问速度的问题。当看到浏览器地址栏出现那个绿色的“安全锁”时，真的比考试拿了满分还开心。

## 💥 终极折磨：Gitalk 评论系统
整个建站过程中，让我最崩溃的绝对是**评论系统**。
原作者使用的是 `Gitalk`，我按照网上的教程，去 GitHub 申请了 OAuth App，填了 `clientID` 和 `clientSecret`。结果呢？不是报 `Network Error`，就是报 `Bad credentials`，或者 `redirect_uri` 报错。

我甚至去问了原作者（阿尔特弗雷），他回复说自己没用代理，都是部署在海外平台所以没问题。Gitalk 这个老古董，在国内网络下彻底水土不服。
更惨的是，在我试图把评论系统强行换成 `Giscus` 时，由于乱改 `Layout.vue` 文件，**我直接把整个网站的排版和侧边栏搞崩了！** 那一刻，看着面目全非的首页，心都凉了。

后来，我通过 GitHub 的提交记录功能，加上直接去原作者仓库复制原版代码，才终于把网站给“救”了回来。

## 🌟 最终的成果
现在，评论框的问题我已经佛系了（实在不行就不显示评论了）。更重要的是，我的网站完美复活了！

- **丝滑访问**：通过 Vercel 部署和自定义域名，国内直接秒开。
- **外观拉满**：原版好看的排版、特效全部保留。
- **灵魂所在**：左下角的阿罗娜看板娘，点她还会跟我说话！

这个网站就像一个数字自留地。虽然踩了无数个坑，看了无数篇官方文档，甚至一度想砸键盘，但看着自己亲手一点点搭建出来的结果，成就感真的爆棚。

建站之旅暂时告一段落，接下来，就是好好写文章啦！（兴许能出一点新功能）
